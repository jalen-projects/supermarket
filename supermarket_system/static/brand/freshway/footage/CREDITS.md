Used only by `templates/shop/freshway/login.html` (the FreshWay demo,
SMMS_BRAND=freshway). MAQAM never loads any of these files.

The recorded clips show screens of this system driven by a script, with a
drawn pointer added so the viewer can follow the clicks. The receipt's
"printing" is the real receipt page revealed from the top down.
