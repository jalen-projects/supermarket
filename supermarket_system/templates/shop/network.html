Yes — two, three or more computers can use this system at once, and they all share the same data. It stays completely offline. Nothing goes to the internet; the computers only talk to each other over your own network in the shop.

How it works

One computer — the one in the office, or the main till — is the server. It is the only one where the system is installed, and it holds the only copy of your data. Every other computer just opens a web browser and types in an address.

That is the whole design. The other tills install nothing. If a sale is rung up on till 2, the stock drops on till 1 and in the office immediately, because there is only ever one set of books. Two separate copies of the system would be two separate shops that disagree with each other by lunchtime — this avoids that completely.

  • The server must be switched on and running the system before the other tills can use it. If it is off, they see nothing.
  • They must be on the same network — the same router, whether by cable or wi-fi.
  • No internet connection is needed at any point. The router does not even have to have one.
  • Everyone signs in with their own name, so Served by on the receipt and the seller reports stay honest.

If the other computer cannot open it

Work down this list. It is almost always the first two.

  1. Is the system actually running on the server? The black Supermarket Management System window must be open there. If it was closed, double-click START SUPERMARKET again.
  2. Windows Firewall is blocking it. This is the usual cause, and it only has to be fixed once. On the server, right-click ALLOW OTHER TILLS.bat in the system's folder and choose Run as administrator. Then try the other computer again.
  3. Are they on the same network? Both must be on the same router. A computer on a phone hotspot cannot see a computer on the shop's wi-fi.
  4. Was the address typed exactly? It needs the http:// and the :{{ port }} at the end. Without the port number it will not find anything.
  5. Did the address change? Routers hand out addresses and can change them after a power cut. Come back to this page on the server to read the current one. If it keeps changing, ask whoever set up the router to give this computer a fixed address.

Things worth knowing before you rely on it

  • The server holds everything. The other tills store nothing at all. Back up on the server, and keep taking that backup to a flash disk.
  • If the server goes off, every till stops. That is the trade for having one honest set of books. Put the server on the same power protection as the fridges, and it is worth having a small UPS on it.
  • A receipt printer prints where it is plugged in. Each till needs its own printer, or its own copy of the printer installed on it.
  • This is safe for a handful of tills, not fifty. Three or four computers in one shop is comfortable. A chain of branches is a different system and a different conversation.
  • Anyone on your network who knows the address can reach the sign-in page. That is fine inside a shop, but it is one more reason every person needs their own password and cashiers stay cashiers — a cashier account cannot see your buying prices or your profit.
